它替你省掉的那些事

六件事原本都要手动折腾，现在都在同一个窗口里。

单文件免安装

一个 exe 就是全部，不写注册表、不占系统目录。不想用了直接删掉，等于卸得干干净净。

多游戏实例

同一个版本想开几份就开几份：一份原版、一份装满模组，存档、设置、模组各自独立。

资源库一体

模组、整合包、光影、材质、数据包五类资源就地搜索，先看简介再一键下载到当前游戏。

正版账号登录

微软账号设备码授权，登录一次就好；凭据用系统级加密存在本机，不上传任何服务器。

Java 自动管理

缺运行时会提示并帮你补齐，版本与游戏不匹配提前就说清楚，不必自己翻日志找原因。

键盘优先

Ctrl + 1~6 切页、F5 刷新、Esc 返回、回车直接在选中的那一行生效，键鼠都顺手。

三步就能开玩

  1. 拿到整包

    去下载页取那个 69.1 MB 的 exe，放到你想放的位置。

  2. 双击运行

    不用解压、不用先装运行库。首次启动会自解压一份运行环境，之后就秒开。

  3. 建个游戏

    在「版本」页选版本、起名字、点「安装并创建」，之后启动这个名字就进游戏。
