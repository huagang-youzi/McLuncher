使用指南

从下载到进游戏

以 Windows 版为例，按顺序做完这几步就能开玩。左侧目录可以直接跳到对应章节。

1. 下载与安装

去下载页拿那个约 69 MB 的 McLuncher-windows.exe。 不需要安装：不用解压、不用先装 .NET 或 Java、也不需要管理员权限。

建议放在一个固定目录（比如 D:\Games\）而不是临时下载文件夹，避免以后被清理掉。

2. 首次启动

双击 exe 即可启动。首次启动需要准备运行环境，会多等几秒，之后再次打开就是秒开。

进入主界面后，顶部会显示当前 Java 运行时的状态：正常时是中性色，缺失或版本不对时变成橙色， 直接点它就会跳到工具页，可以一键补齐。

3. 建一个游戏

「版本」页分成上下两部分：上半部分是已经建好的游戏，下半部分是可安装的官方版本。

  1. 在下面的版本列表里选中一个版本（比如 1.20.1）。
  2. 点「安装并创建」。
  3. 给它起个名字——默认就是版本号，你也可以改成“生存”“生电”之类。
  4. 等文件下载完，回到上面列表，启动这个名字就进游戏。

同一个版本可以建多份：模组、存档、设置全部各自独立，互不串档。名字全机唯一， 重名会自动加「（1）」后缀；想复用某个名字，先把占用它的游戏删掉。

4. 管理游戏

改名：选中游戏后点上方「改名」。

删除：选中后点「删除」。默认只删记录、保留文件夹； 如果确定连存档和模组一起清掉，在弹窗里勾选“同时删除文件夹”。

打开目录：想手动塞个存档或者看日志，用「打开目录」直接跳到实例文件夹。

按钮点不动时把鼠标停上去，会说明原因，比如“还没有游戏”“版本文件还没下载完”。

5. 资源库与整合包

「资源库」支持模组、整合包、光影包、材质包、数据包五类资源， 数据来自公开的资源接口，可以按关键词搜索，也可以按类型筛选。

  • 双击任意条目，或点「查看简介」，进入详情页：左侧看图，右侧看说明与版本。
  • 点「下载到当前游戏」，文件会直接落到当前实例对应的目录里。
  • 整合包更省事：一键装好依赖，并自动创建一个独立游戏，不和你现有的实例混在一起。
  • 按 Esc 可以从详情页退回列表。

6. 键盘快捷键

整站（整个客户端）都是键盘可用的，常用组合如下：

按键 作用
Ctrl + 1 ~ 5 依次切到 首页 / 资源库 / 版本 / 工具 / 账号
Ctrl + 6 打开设置
F5 刷新当前页数据（版本清单、Java 列表、资源库等）
Esc 从资源简介退回列表
Enter 在版本列表里对选中的那一行生效：游戏行直接启动，版本行安装并创建

下载与安装进行时，窗口底部会出现一条细进度线，进度跑完自动收起。

7. 校验文件

下载页给出了 SHA-256 校验值。想确认文件完整，在 PowerShell 里运行：

Get-FileHash .\McLuncher-windows.exe -Algorithm SHA256

输出的哈希应与下载页显示的一字不差；对不上就重新下载，不要直接运行。

8. 遇到问题时

  • 启动时报 Java 相关错误：点顶部的 Java 状态胶囊去工具页补齐对应版本。
  • 下载中断：支持断点续传，重新点一次下载会接着之前的进度继续。
  • 其他疑问：先看问答页，再看状态页确认站点是否正常。
